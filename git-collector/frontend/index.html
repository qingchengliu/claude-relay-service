💻 本地怎么使用

参考 git-ai 官方文档：无需按仓库单独配置，照常 prompt、commit，AI 归因会自动追踪。

git status git add . git commit -m "feat: your change" git push # 查看当前工作区 AI / 人工归因 git ai status # 查看提交统计、行级归因和变更归因 git ai stats --json git ai blame src/example.py git ai diff HEAD

照常使用 Git

git 会代理到原生 Git，日常 commit、push 不变。

查看工作区归因

git ai status 显示当前改动中 AI / 人工比例、接受率和等待时长。

查看提交统计

git ai stats 支持单个提交、提交区间和 --json 输出。

查看行级来源

git ai blame <file> 类似 git blame，但会显示 agent、模型和会话来源。

查看带归因 Diff

git ai diff HEAD 或区间 diff 会标注每行来自 AI 还是人工。

查看 Prompt 记录

git ai show-prompt <id> 可按 prompt id 回看生成上下文。

🧭 主要功能

AI 代码归因

把 AI 写入的代码行关联到 agent、模型和生成它的会话记录。

本地优先

本机可离线工作；归因写入 Git Notes，会话指针和内容保存在本地 SQLite。

Prompt 安全留存

Prompt / transcript 不直接塞进 Git 仓库，可同步到团队自托管存储。

生命周期追踪

在 rebase、cherry-pick、stash、amend 等操作后继续迁移 AI 归因。

团队统计看板

汇总成员、仓库、工具、模型、接受率、存活率和趋势数据。

cc-switch 兼容

安装时把 hooks 注入 provider 配置，切换 endpoint 后仍可追踪。

官方命令参考： https://usegitai.com/docs/cli/reference

📖 安装过程做了什么

1

下载 git-ai 客户端

自动检测系统架构，从 GitHub 下载预编译二进制

2

安装到本地

安装到 ~/.git-ai/bin，创建 git 命令代理

3

写入配置

自动配置服务端地址和团队 Key，无需手动操作

4

安装 IDE 钩子

自动对接 VS Code / Cursor 等常见 IDE

5

配置 PATH

自动添加到 shell 配置文件，重新打开终端即可用

!

重要说明

安装后 必须关闭并重新打开终端 才能生效。
安装不会改变你的 git 工作流，git commit 照常使用。
